# RDQ 需求規格：2027 AACRT 多語言智慧大腦 Web App (Rev 3)

## 一句話任務
為 2027 AACRT 國際年會打造免安裝、支援英/日/韓/中四語的志工與外賓現場智慧問答 PWA，結合本地快捷 FAQ 與 Gemini 雲端對話，串接獨立問答監控試算表與即時推播，具備志工「一鍵放大秀給外賓看」與實體名牌背卡 QR Code 輸出，並嚴格鎖定 $50 美元預算上限防護牆。

## ✅ 已確認
- 專案面向：**2027 AACRT** 與 **TWSRT 第 60 次年會**，地點於**台北南港展覽館 2 館（TaiNEX 2）**，時程 **2027 年 4 月 24～25 日**。（Ⅰ）
- 介面定位：採「雙用大會官方版」，大會皇家海軍藍×榮耀琥珀金視覺，頂部支援**英／日／韓／繁中**一鍵切換，外賓與志工皆可直接操作。（Ⅲ）
- 問答架構：採**「60/40 混合式」**，60% 常規問題（交通、Wi-Fi、地圖、基礎作息）為快捷展開卡片；40% 自由提問由 **Gemini Flash API** 秒回。（Ⅲ）
- 運作模式：免開本機電腦 24 小時運轉，前端靜態託管於 **GitHub Pages**，大會知識庫母本存於 Google Drive（創作庫），由 Agent 提煉公開大腦發布至雲端安全區，不暴露個人 Drive。（Ⅱ）
- 後端架構：建立**全新的獨立 Google 試算表「2027 AACRT 現場問答監控儀表板」**（與志工報名表分開），所有提問內容、語言、時間自動非同步寫入。（Ⅲ / Rev 3 確選 1B）
- 即時通報機制：當後端偵測到特殊求助、緊急狀況或抱怨反饋時，**自動發送即時通知推播至 Leader 手機**。（Ⅲ / Rev 3 確選 2B）
- Token 預算防護牆：**硬性設定預算上限為 $50 美元（約 NT$ 1,600）**，支撐 50,000+ 次對話，杜絕超額帳單。（使用者確認）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 後端中繼技術 → 預設沿用 **Google Apps Script Web App**，無需額外購買 Cloudflare 或雲端主機。
- 即時推播管道 → 預設透過 Google Apps Script `MailApp.sendEmail` 自動發信至 Leader 信箱（或串接 Telegram Bot / LINE Notify Webhook）。

## ➕ 已採納（象限Ⅳ）
- **PWA 離線快取（Service Worker）**：展館弱網或無網環境下，核心會議室地圖與基礎 FAQ 仍可順暢離線讀取。
- **大會緊急跑馬燈公告**：連動 Google Sheets 首列，Leader 在手機試算表改字，所有在線使用者畫面即時跳出緊急公告。
- **AI 嚴格防呆與導流大會諮詢台**：未授權或未列於大腦之資訊一律禮貌拒絕並導引至現場**「大會諮詢台」**，零公關風險。
- **外賓語音輸入支援**：支援瀏覽器語音辨識，外國學者可直接對手機說英文或日文提問。
- **實體名牌背卡與立牌 QR Code 產出（盲點 1）**：於專案 `產出-成果層/` 產出大會志工識別證背卡專用尺寸向量/高解析 QR Code 圖檔，方便現場即掃即用。
- **一鍵放大秀給外賓看 Show-to-Guest 模式（盲點 2）**：前端卡片與 AI 回覆加入全螢幕大字體展示按鈕，學生志工不需開口，按一下即可轉向手機螢幕向外籍學者清楚展示。

## ❌ 排除項（明確不做）
- 不做外人直接穿透讀取個人 Google Drive 私密檔案的架構（杜絕資安與鎖檔風險）。
- 本地電腦不架設 Web 伺服器，不讓 Antigravity 24 小時常駐當主機。
- 暫不實施盲點 3（紅色緊急關鍵字強制彈窗）與盲點 4（自動信用卡號脫敏），保持問答流程流暢簡約。

## 📋 一段式需求規格
為 **2027 年 4 月 24 至 25 日** 於 **台北南港展覽館 2 館** 舉辦之 **第 26 屆 AACRT** 打造大會專屬「智慧大腦 Web App（PWA）」。系統採用 **GitHub Pages** 靜態託管搭配既有大會皇家海軍藍×琥珀金設計系統，提供 **English、日本語、한국어、繁體中文** 完整多語言介面與台北即時時鐘。核心功能分為「60% 常用快捷 FAQ」與「40% Gemini 智能對談」，支援外賓語音輸入，並為學生志工提供**「一鍵全螢幕放大秀給外賓看（Show-to-Guest）」**功能。後端建立獨立 Google 試算表**「2027 AACRT 現場問答監控儀表板」**紀錄所有提問，遇到特殊求助時自動推播通知 Leader 手機；專案產出層提供**識別證背卡專用 QR Code 印刷檔**；大腦已注入 AACRT 放射專案字典與 GDPR 規範，未公開項目導流至「大會諮詢台」；API 營運設定 **$50 美元（約 NT$ 1,600）** 預算上限防護牆，確保大會現場極致穩定且安全無虞。
